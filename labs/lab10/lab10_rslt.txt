--- 2 Core Cache Performance Gain ---

The 2 core cache performance gain cannot be calculated from the values shown above,
because no dual core Cache OFF timings were provided.

To calculate it, the following formula should be used once the dual core values are available:

2 core cache speedup = (dual core Cache OFF time) / (dual core Cache ON time)
2 core time reduction = ((Cache OFF - Cache ON) / Cache OFF) x 100%


=============================================================
Observations
=============================================================

The XIP cache has a major impact on execution speed. On 1 core, the total execution
time decreases from 6035543 us to 1079471 us, giving an overall speedup of 5.59x.

The single precision function benefits more from the cache than the double precision
function. The float version achieves a 7.46x speedup, while the double version achieves
a 4.73x speedup.

This suggests that the float implementation is more heavily affected by memory access
delays when the cache is disabled.

Even with the cache enabled, the double precision function is still much slower than
the single precision function. This shows that double precision arithmetic remains more
computationally expensive on the RP2040.

Overall, the results show that enabling the XIP cache greatly improves performance,
especially for the single precision calculation, and significantly reduces the total
runtime of the benchmark.
